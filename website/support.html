Open a support request

Open GitHub support

For account, privacy, or billing matters, ask for a private contact route first. GitHub issues are public by default.

Include useful context

  • What you expected and what happened.
  • The app version shown in the bottom status bar.
  • Your Windows version and whether the issue affects the website, installer, or desktop app.
  • A short reproduction path and any non-sensitive error message.

Never include credentials

Never post Roblox cookies, passwords, session tokens, full authorization headers, payment card numbers, or private account exports. Virgue support does not need them.
