Everything you need to keep a Roblox setup under control.

Virgue is a Windows workspace for profiles, game collections, server discovery, and live session state. Each view answers one practical question.

Accounts stay readable.

Group profiles by game and category, search them quickly, and keep the selected account's details in view. The desktop app stores the local workspace on the computer where you use it.

  • Search and sort profiles
  • Assign games and categories
  • Import and export local data
  • Launch one account at a time on Free

Games give the workspace shape.

Keep each Roblox experience in its own collection and use categories for the way you actually play. Profile and game limits stay visible in the app.

  • Game collections and categories
  • Place and universe information
  • Favorites and recent activity
  • Two game collections on Free

Sessions show the truth.

Follow running Roblox clients, presence checks, and session history from a single board. The app makes it easier to tell a live session from a stale window.

  • Live process and presence state
  • Session history and activity
  • Server and Job ID context
  • Guardian tools on the Pro roadmap

Settings stay close to the work.

Choose workspace behavior, watcher rules, client defaults, privacy controls, and local integration access without hunting through unrelated screens.

  • Workspace and watcher controls
  • FPS and ClientAppSettings defaults
  • Privacy and local API settings
  • Plan access in one settings area
